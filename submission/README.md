# 交付与投稿

make bundle 在完成校验后生成 generated/manuscript-bundle.tar.gz。它是本地复现归档，不等同于某个期刊的最终投稿包。

归档包含 PDF、图表、正文源文件、BibTeX、示例原始数据、分析代码、环境锁文件、输入文件 MD5 清单和 Git 基准提交/未提交状态。解压后进入 manuscript-bundle/，运行 make check 可重新构建。

打包采用 package.R 中的明确白名单，不包含 .git、.env、安装的 skills、全文缓存或检索历史目录。原始数据在白名单内；替换真实数据前按权限修改，不能默认用于受限数据。

投稿前按目标期刊准备标题页、匿名稿、补充材料、封面信、作者贡献、伦理和共享声明。审稿回复可新增到此功能目录，保留决策版本。
