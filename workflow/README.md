# 流程维护

根目录 Makefile 是统一入口。common.R 读取公共配置，并在存在时激活项目 renv 环境；各阶段脚本从项目根目录执行。

- environment.R：显式恢复或记录 R 环境，可能联网；普通构建不安装外部软件。
- session.R：写出 R 会话、随机种子和原始输入校验和。
- check.R：复算结果、检查生成物和 LaTeX 引用及溢出警告。
- clean.R：只清理固定的自动生成目录，保留原始数据、正文、检索记录和环境。
- preview/：临时 PDF 页面预览，不纳入 Git 或投稿包。

新增分析步骤时为其输出建立单独文件目标，并声明实际输入、执行脚本、公共配置和环境锁文件依赖。不要仅靠“上次似乎运行过”来跳过任务。单独修改正文由 latexmk 处理，无须触发 R 分析。

make test check 是基本验证。修改依赖或打包逻辑后，额外验证 make clean 后重建、重复构建跳过计算，以及解压复现包后运行 make test check。
